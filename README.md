# Crowdsec_Webmin
This is a webmin module for Crowdsec

I take no credit as it is a pure prompt project.

I do not intend to actively maintain this so please fork the repo if you want to take it further.

Webmin should be on the same instance as the crowdsec engine.
It uses the local API to pull metrics. 
There are no data rate limits like the equivalent cloud console.

Install:
  Go to Webmin -> Webmin Configuration -> Webmin Modules -> Install -> From uploaded file. 
  Simply upload the crowdsec.tar.gz file.
  The new module should appear under either the Networking tab.
